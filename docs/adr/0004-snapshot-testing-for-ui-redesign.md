# Adopt snapshot testing for view-layer regression coverage

Existing tests cover domain logic only (engines, `Match`, `Scoresheet`); nothing asserts what a screen actually renders. Reskinning every screen onto a new design system makes visual regressions easy to introduce silently, so we decided to add [swift-snapshot-testing](https://github.com/pointfreeco/swift-snapshot-testing) as a test-target dependency and record snapshots per screen/theme (Paper/Felt) as the design-system components land. Alternative considered: rely on manual simulator checks only — rejected because the redesign touches every screen at once and manual review won't scale across future changes. Consequence: snapshot fixtures need periodic re-recording when a screen's design intentionally changes, and CI must run on a consistent simulator/OS to avoid flaky diffs.
