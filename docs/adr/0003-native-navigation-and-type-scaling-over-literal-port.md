# Reskin onto native SwiftUI navigation and scalable type, not a literal port

The prototype is a single hand-rolled `screen` state machine with fixed-pixel font sizes and no push/pop navigation — it's a web mockup, not an iOS app. We decided to match its visual chrome (colors, fonts, custom components like pills/chips/dot badges/keypad) exactly, but keep SwiftUI's native `NavigationStack` (back-swipe, platform transitions) instead of reimplementing the state machine, use a native bottom sheet for the Rejoin prompt instead of the prototype's custom slide-up overlay, and translate the prototype's fixed pixel sizes into scalable semantic text styles instead of copying them verbatim. This trades pixel-exact typography and literal mechanics for Dynamic Type support, VoiceOver-correct navigation, and less bespoke plumbing to maintain. Consequence: text at large accessibility sizes will reflow rather than clip or stay fixed, and screen transitions use UIKit/SwiftUI's native animations rather than the prototype's own curves.
